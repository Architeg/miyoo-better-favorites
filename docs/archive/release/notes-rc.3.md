# Better Favorites v1.0.0-rc.3

> Historical engineering record. Use [current installation instructions](../../install.md) and [release notes](../../release/notes-rc.7.md).

Your existing Onion favorites, easier to browse: console groups, display preferences, long-title scrolling, shoulder paging, theme-aware menus and safe favorites-record removal. Onion still handles games, saves, recent history and GameSwitcher.

## Downloads and quick start

This follow-up candidate is not publicly released. Full and app-only packages, source companions and SHA256SUMS are prepared locally from the identified source tree. GitHub Source code archives are for developers.

For the full package: power off, connect the card, copy App/BetterFavoritesTest into App, open the computer launcher there, choose Install / Update, wait for success, eject and boot. Both supported integrations are prepared; their switches start OFF. Apps access always remains available. Complete uninstall uses portable card recovery and restores originals before removing owned app/data/tool files.

## Compatibility

Designed for Mini and Mini Plus; hardware tested on Mini Plus. Tested device: MY354, firmware 202306282128, Onion v4.3.1-1; hardware revision unknown. Earlier normal-flow tests passed on Windows7 SP1 x64, Windows10 x64 and Mac M1 Ventura13.7.8. New click workflow awaits its exact-package device test. Other combinations welcome community testing.

## Limits and feedback

Audited system-file hashes are required for integrations. Linux desktop launch behavior varies; unsigned host tools may require a file-specific Open/Trust confirmation. Missing/conflicting recovery stops removal. Concrete dependency redistribution questions are recorded in the dependency audit; this is not stable v1.0.0.

Report bugs with version/package hash, computer and Miyoo/Onion details, steps and a privacy-reviewed diagnostic export. No device Terminal commands are needed.

# Better Favorites 1.0.0-rc.4

> Historical engineering record. Use [current installation instructions](../../install.md) and [release notes](../../release/notes-rc.7.md).

One ready-to-install ZIP: copy `App/BetterFavorites` to your powered-off Miyoo card, open the computer launcher there, and choose Install / Update. Both compatible integrations are installed; fresh switches stay OFF. Updates preserve preferences. Verified BetterFavoritesTest installations migrate without losing original system backups.

The Mac launcher retains a clearly named verified helper for file-specific security approval and retry. Neither Gatekeeper nor Windows protection is disabled. Complete uninstall verifies stock restoration, preserves a computer recovery archive, and removes only owned app/data and integration artifacts.

Designed for Mini and Mini Plus; hardware tested on Mini Plus (MY354, firmware 202306282128, Onion v4.3.1-1, hardware revision unknown). Renamed-package acceptance remains pending. No new game/UI/audio features. Source/dependency companions are developer assets, not alternative installers. RC2 remains immutable.

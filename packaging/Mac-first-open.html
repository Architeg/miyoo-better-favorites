Better Favorites: Mac first open

This guide works offline. Read it before opening the installer.

macOS may ask you to approve this unsigned installer. Download it only from the official Better Favorites release. Follow the file-specific approval steps below.

There may be two separate approvals: first Install-macOS.command, then the compiled BetterFavorites-Installer helper. Approving the first does not approve the second. A new helper version may need approval again.

1. Prepare

  1. Power off the Miyoo and mount its SD card on the Mac. Keep it powered off until installation finishes.
  2. Extract the package and copy its App/BetterFavorites folder into the card’s App folder. Keep recovery backups.
  3. Open Install-macOS.command inside the copied folder. If an unsigned/unidentified-developer warning blocks it, follow step 2.

2. Approve the script, if blocked

  • Monterey: Apple menu → System Preferences → Security & Privacy → General.
  • Ventura and later: Apple menu → System Settings → Privacy & Security. Scroll to the Security section.

Find the message for the file you just tried to open. Choose Open Anyway, authenticate if asked, and confirm Open. This option appears after a blocked attempt and may be time-limited. If absent, try opening the file once more and revisit the settings page. A managed Mac may not allow exceptions.

3. Approve the helper separately, if blocked

Terminal may open successfully while macOS blocks BetterFavorites-Installer. Use the same settings page to approve that specific file. The terminal shows its exact retained path; use Finder → Go → Go to Folder to locate it if needed.

Leave Terminal open. After approval, enter r to retry. You may enter s to open System Settings/Preferences. The helper stays at a stable path on your Mac and its bytes are checked before every retry. The installer does not remove quarantine.

4. Install or uninstall

Choose 1 — Install / Update or 2 — Uninstall completely. Confirm the powered-off card when asked. Optional integrations remain separate from their default-OFF app preferences. A successful complete uninstall restores verified originals and removes owned app files; it retains a recovery archive on your computer.

Keep the card connected while progress reports the actual work. Wait for verified success before safely ejecting the card in Finder.

To report a problem, reopen the same launcher and choose 3 — Export diagnostics. It prints a fresh archive path on your computer. Review the archive before sharing; it includes bounded installer log tails and may contain personal file paths.

If something fails

Deleting the app folder does not restore system patches. Keep the card’s recovery files. Re-copy the current package and choose Uninstall completely for verified restoration and cleanup, or Install / Update for authenticated repair. A missing app receipt can be repaired only when the surviving journal, originals and installed system files agree. Unknown changes are preserved; share the actual reason and log instead of editing system files manually.

“Installation failed” is not a security prompt. Read the reported change state and next action. The detailed log is normally in ~/BetterFavorites-Logs/. Preserve unknown files and recovery backups; do not delete files merely to bypass validation. If restoration is unresolved, keep the Miyoo powered off and use the package’s recovery guide.

Status 137 means a possible SIGKILL termination; it does not prove Gatekeeper was responsible or establish the card’s state. Only use the approval steps when macOS actually displays an unsigned/unidentified-developer warning.

Stop for malware, damaged-file, or organization-policy warnings. Do not override them using these instructions. Do not disable Gatekeeper or other protections. Checksums help detect changed downloads; they are not a security audit.

Online reference: Apple: opening apps safely. No internet connection is needed to use this guide or the packaged installer.
